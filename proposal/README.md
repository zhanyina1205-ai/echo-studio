# 回声 · 独立产品试用提案

这是「回声」的独立提案网页，与工具一起发布在同一个GitHub仓库。提案网页不修改工具数据，也不改动「这一场」。

## 内容结构

封面 → 为什么做 → 四个工作场景 → 四步处理演示 → 分类与语境 → 演员、工作室和观众的价值 → 已实现与未实现 → 七天试用建议 → 试用入口。

所有留言、情境、时间与演示口径均为虚构，不代表李一桐本人或其工作室的工作习惯、已验证需求、合作或背书。试用计划为建议，尚未执行；没有虚构使用成效或推荐语。

## 交互

- 手机章节目录、锚点导航与阅读进度；目录支持 Escape 关闭。
- 四个工作场景切换，标签支持方向键、Home 与 End。
- 四步虚构演示：人工校正标记、语气切换、生成示意稿、主动确认、口径变更阻止旧稿确认、事件原话、4条样本的简报。
- 演示状态仅保存在页面内存。刷新或重置即清除；不会读写「回声」真实数据库，不复制、不发送、不发布。
- 实际界面截图可放大，支持 Escape 关闭；FAQ 可展开。
- 标准浏览器打印入口与 A4 打印样式。打印当前所选的演示步骤，不包含所有交互状态；系统另存PDF对话框与分页尚未实际验证。

## 真实能力边界

本页明确区分规则模板、本地工作台与后续候选方向：没有将实时监测、AI语义分析、平台授权、自动发布、团队审批或云备份描述为已实现。演员专属视图与跨设备共享也不在当前版本。

“31项测试”指现有「回声」工具的测试记录。本提案自身11项测试通过；实际浏览器验证与限制见 `QA.md`。没有统计追踪、数据采集或业务网络调用。

视觉素材及生成提示词见 `ASSETS.md`。构建不需要安装第三方依赖。
