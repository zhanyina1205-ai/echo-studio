01 / THE SPACE BETWEEN VOICES问题不只是“留言太多”。
not louder. more thoughtful.

她在镜头前。
工作室在
很多声音之间。

宣传、作品与活动之外，
每一句“想问一下”，都需要有人判断。

一句批评，可能是在说角色，也可能是在说字幕。一个反复出现的问题，可能需要一条说明，也可能应该先查清楚，而不是立刻回应。

这份提案不把粉丝沟通理解成“统一话术”。它想帮助工作人员，把原话、事实依据和接下来的动作放在同一个地方。

以上为待验证的工作场景假设，不是对任何演员团队内部流程或个人生活的调查结论。

01 / 容易散

看过这条，
后来找不到原话。

截图、表格与聊天里的记录，需要重新拼出上下文。归纳越快，越容易只剩一句转述。

先把原话留在场。
02 / 容易混

想写得亲切，
却可能多说了一句。

时间、安排或演员本人的感受，不能仅凭语气顺畅就被写进回复。

语气之前，先有依据。
03 / 容易断

回复之后，
问题不一定结束。

多条留言可能指向同一件事。有没有核实、下一步做什么，需要留下能继续看的记录。

让回应之后，还有后续。
讲解提示 / 这一页想表达什么

我们不是给演员加一个需要亲自盯的后台，而是给工作室一个有边界的小工作台。它的价值不是回复更多，而是减少上下文丢失和没有依据的表达。这里的需求仍然需要由真实使用来验证。

02 / IN THE STUDIO'S EVERYDAY把工具放进工作，不让工作围着工具转。

不需要再多一个后台。
只在这几个片刻，接住事。

场景中的时间为叙事示意，非真实行程。
点击卡片，看看谁来用、怎么用。

↳ 演员不必阅读全部留言。建议由工作室整理后，再由本人决定是否回看；这不是当前 MVP 的独立账号或权限功能。

04 / CONTEXT BEFORE LABELS不能只问：“今天正面还是负面？”

07 / START SMALL, LEARN SOMETHING REAL先验证“有用”，再追求“全面”。

先从一个主题，
试七天。

建议试用方案，尚未执行。
先用虚构样本，再确认真实资料能否使用。

DAY 01 / 建立边界

只选一个主题。

例如一次公开活动。由一位工作人员先试用，确认录入范围、有效口径和备份方式，不接全部业务。

DAY 02–06 / 走通闭环

用一小批资料，认真处理。

在素材获准后，手工导入选定留言；逐条检查规则建议，修改草稿，记录后续。仍由人到平台发布。

DAY 07 / 回看取舍

问“还愿不愿意用”。

回看真实使用记录与工作负担。让工作人员指出哪里省了翻找，哪里反而多了一步，再决定是否继续。

questions worth asking.

试用结束，不看漂亮的数字。先回答：

  1. 一条转述，能不能方便地找回原话？
  2. 过期或不确定的口径，有没有被及时拦住？
  3. 值得跟进的问题，下一次还能不能接上？
  4. 团队愿不愿意第二周继续用？演员是否自愿觉得摘要有帮助？

这些是试用评价问题，不是已经获得的使用结果或节省时间承诺。

开始之前，可能会问。

它和表格、聊天记录有什么区别？＋

不是说表格不能用，而是把“原话—口径版本—回复草稿—后续事件”放进连续流程。值不值得从现有习惯切换，需要用试用结果判断；不强求替换已经顺手的工具。

会替演员说话，或者自动去回复吗？＋

不会。当前只按模板准备草稿，人工核实和确认后才能复制。复制不代表发布，也不替演员编造个人感受、行程或承诺。发布仍由有权限的工作人员在原平台完成。

演员本人需要天天打开吗？＋

不需要以此为目标。主要使用者是工作人员。建议团队先筛选相关反馈，再与本人沟通；演员可以决定是否看。当前没有演员专属摘要页、多人共享或账号权限。

以后能做关键词实时监测吗？＋

可作为下一阶段研究方向，但要先确认平台允许的接口、授权范围、采集覆盖与运行成本。现在没有后台监测任务，也没有全网数据，不会用示例图表冒充实时结果。
